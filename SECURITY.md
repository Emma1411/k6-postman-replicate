# Politique de sécurité

## Signaler une vulnérabilité

N'ouvre pas de ticket public. Utilise le signalement privé de vulnérabilités de GitHub (onglet Security du dépôt)
ou écris à : <adresse à renseigner>.

Merci d'indiquer : version, étapes de reproduction, impact estimé. Tu recevras un accusé de réception, puis un suivi
jusqu'à la correction.

## Périmètre

Dans le périmètre : contournement de la protection SSRF, dépassement des limites, fuite de secrets, exécution de code,
XSS dans les rapports. Voir `docs/security.md`.
